Integração TikTok for Developers

Demonstração web do fluxo ponta a ponta: Login Kit (OAuth), troca de código por token e Display API (perfil e lista de vídeos). Use o app em Sandbox no portal e uma conta target user.

Configuração (uma vez)

Roteiro sugerido para o vídeo (.mp4 / .mov)

  1. Abrir https://alexandreaguiaralves.github.io/ e mostrar links de Privacidade e Termos.
  2. Entrar em /demo/ (esta página) — domínio visível na barra de endereço.
  3. Clicar Entrar com TikTok → login/consentimento na sandbox.
  4. Na volta, mostrar perfil e tabela de vídeos carregados via API.
  5. Mencionar scopes usados (Login Kit + Display API). Remova produtos/scopes não usados no portal antes do review.
